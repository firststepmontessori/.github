# First Step Montessori organization defaults

This repository provides the public GitHub organization profile and shared
community-health files for First Step Montessori School.

- School profile: [`profile/README.md`](profile/README.md)
- Website source: [`firststepmontessori/firststepmontessori`](https://github.com/firststepmontessori/firststepmontessori)
- Contribution guidance: [`CONTRIBUTING.md`](CONTRIBUTING.md)
- Security reporting: [`SECURITY.md`](SECURITY.md)

The repository deliberately contains no child names, photographs, consent
records, private contact lists, credentials, or unverified school claims.
Organization profile and shared contribution guidance for First Step Montessori.
