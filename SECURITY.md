# Security policy

## Supported work

Security updates apply to the current website and its active deployment
configuration.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, personal information or child
safety concerns in a public issue. Use GitHub's private vulnerability reporting
feature on the affected repository when it is enabled. If that feature is not
available, contact an organization owner privately through GitHub.

Include only the minimum information required to reproduce and assess the
problem. Never include real child, parent or staff data in a report.
